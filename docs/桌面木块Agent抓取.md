# 桌面木块 Agent 抓取

## 运行范围

此流程连接 `piper_tabletop_sim_ws` 的 PiPER + D435i + 4 cm 木块场景，以及 `real_piper_yolo_graspnet` 的 YOLO、GraspNet、MoveIt 抓取执行器。Agent 使用独立的 ROS 域 67 与 Gazebo 分区 `tabletop67`，自动启动和停止模块。

当前流程是**实时感知 → 抓取候选筛选 → MoveIt 彩排 → 正式抓取 → 抬升 → 60 秒保持验证 → 原位下降 → 松爪放回桌面 → 机械臂回零**。放置位置是木块原位附近。该流程只在仿真单木块场景验证，不能据此宣称真机抓取成功率。

## 启动与对话

```bash
source /opt/ros/humble/setup.bash
.venv/bin/python agent.py --mode sim --profile grasp --auto-confirm-sim
```

在 Agent 终端依次输入：

1. `请在桌面木块仿真中彩排抓取。`
2. 彩排任务结束后，`查询桌面木块抓取任务状态。`，确认 `result.success=true` 和 `token_issued=true`。
3. `请正式抓取桌面木块，保持后放回桌面并回零。`
4. 查询正式任务状态，确认 `result.success=true`、`result.pick_success=true`、`result.placed=true`、`lift_m >= 0.06`，并检查 `held_samples_xyz` 中所有高度均在初始高度之上至少 0.06 m，以及 `placed_xyz` 回到桌面。
5. `请停止桌面木块仿真及其感知模块。`

首次彩排会自动启动 Gazebo、MoveIt、反馈中继、YOLO 和 GraspNet，可能需要数分钟。`dry_run=true` 只做规划，不移动机械臂。正式执行使用**本轮新采集的感知帧**重新生成候选并预检；不复用彩排 CSV。首次执行时木块相对彩排位置移动超过 15 mm，会要求重新彩排。仿真夹爪反馈若接近全开或全闭，执行器判为未抓牢并回零；Agent 最多用两次不同的实时帧尝试抓取。失败后的重试允许木块在桌面上水平移动不超过 80 mm，仍须重新获取候选及通过 MoveIt 预检。Agent 退出时默认停止它启动的模块。

如需看画面，可另开终端进入同一个 ROS 域，运行 `gz sim -g` 或 RViz；Agent 默认以无界面方式启动仿真。工具的配置在 `config/tabletop_pick.yaml`，模块命令在 `scripts/tabletop_module.sh`，任务逻辑在 `tools/tabletop_pick.py`。

## 数据与判定

- YOLO 桥接输出 `last_validation.json`，GraspNet 输出 `perception_grasps.csv`。任务要求 CSV 在任务启动之后更新，且与验证文件时间相近。
- Agent 检查候选与分割木块中心距离、夹爪朝向及规划可达性。`tabletop_candidate_provenance.json` 记录源 CSV 与验证文件时间戳；`tabletop_candidates_sim.csv` 是执行专用快照，源 CSV 不会被修改。
- 由于当前 GraspNet 对 4 cm 木块给出约 72–100 mm 的开口，而仿真小夹爪最大开口仅 70 mm，快照中的开口固定为已知物体宽度 40 mm；候选位置使用当前分割中心，保留 GraspNet 的 6D 朝向。这些修正仅用于仿真，不能直接带到真机。
- 夹爪反馈和执行器结果之外，还从 Gazebo 读取木块真实位姿。正式结果需要抬升至少 6 cm，并在 60 秒内每 5 秒采样均保持在阈值以上。之后执行器下降到抓取位姿上方 3 cm，松开夹爪、退回抬升位姿并回零；Agent 检查木块最终高度与初始高度相差不超过 12 mm，水平位置相差不超过 50 mm。`job.status=succeeded` 仅表示后台函数正常结束，抓取结论须看 `job.result.success`、`pick_success` 和 `placed`。

## 实测记录

2026-10-29 连续进行了两次各自重启仿真的 Agent 工具闭环测试。两次彩排和正式执行均通过；正式执行读取的实时 CSV 时间戳分别晚于对应彩排帧，未复用旧快照。

| 运行 | 初始木块 XYZ (m) | 保持后 XYZ (m) | 抬升 | 放回后 XYZ (m) | 结果 |
| --- | --- | --- | --- | --- | --- |
| 第一次 | `[0.620, 0.100, 0.570486]` | `[0.616167, 0.108961, 0.648286]` | 77.8 mm | `[0.621490, 0.082868, 0.570484]` | 抓取、保持、放回、回零通过 |
| 第二次 | `[0.620, 0.100, 0.570486]` | `[0.618764, 0.097184, 0.681064]` | 110.6 mm | `[0.613686, 0.091604, 0.570484]` | 抓取、保持、放回、回零通过 |

每次 60 秒内的 12 次保持采样均通过，放置服务报告松爪开口约 70 mm 且回零成功；两次结果均为 `result.success=true`、`pick_success=true`、`placed=true`。这些数据只证明这两次仿真运行，不是成功率统计。

随后两次自然语言复测在正式执行中观察到木块短暂抬起后于保持阶段滑落，Agent 正确返回 `result.success=false` 并跳过放置。仅增大仿真指垫与木块的接触摩擦参数没有消除滑落。核对分割中心与 Gazebo 真值后发现感知高度约偏高 8.5 mm，因此将仿真 `grasp_z_offset_m` 从 0.0185 调为 0.0235，让指垫接触更靠近木块中心。此修正和摩擦参数都只作用于仿真。

修正后的自然语言对话测试完成完整闭环：彩排成功后 Agent 调用正式抓取，木块抬升 83.1 mm，12 次保持采样通过，放回木块位姿为 `[0.658413, 0.114804, 0.570484]` m，执行器报告松爪及回零成功。水平放回误差约 41 mm，接近当前 50 mm 容差上限，仍需继续评估重复性与放置精度。

下一次独立运行中，一个开合轴相对方木边缘偏约 32° 的候选把木块推离重试区域。为此，仿真 Agent 现在根据场景中固定的木块偏航角 `0.28 rad`，只接受开合轴与任意一对对边夹角不超过 15° 的候选；同时保留重试被阻止前的失败结果。该方向筛选后的独立闭环测试抬升 101.9 mm，12 次保持采样通过，放回木块位姿为 `[0.623659, 0.091401, 0.570484]` m，水平误差约 9 mm，松爪与回零成功。方向筛选使用已知仿真木块姿态，不适用于未知姿态的真机目标。

## 已知限制

- 场景只含单个固定尺寸木块；未覆盖不同尺寸、遮挡、多目标或长期重复抓取。
- 已出现保持阶段滑落和斜夹推走木块的失败运行；当前成功运行数量不足以估计稳定成功率。
- 保持验证为有限时长，不能保证长期不滑落。
- 当前放置为原位放回，没有可配置目标位姿，也没有单独的放置轨迹预检。松爪后会检查木块落桌位姿，但尚未验证转运至另一位置。
- 使用已知 40 mm 物体宽度和简化指尖碰撞垫来校准仿真接触。真机需要重新测量相机标定、夹爪几何与执行误差，不能直接套用这些仿真参数。
