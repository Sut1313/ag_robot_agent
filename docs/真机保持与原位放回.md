# ROSA 真机抓取保持与原位放回

真机启动方法见 [PiPER 真机测试手册](https://github.com/Sut1313/real_piper_yolo_graspnet/blob/main/docs/REAL_ROBOT_TEST_RUNBOOK.md)。驱动须在启动时设置 `gripper_forward:=false`，让 Piper SDK 单独控制夹爪。真机 ROS 域须能接收该驱动发布的 `/joint_states_feedback`，并能使用 MoveIt 规划与执行接口。

在同一 ROS 域启动 ROSA。

```bash
source /opt/ros/humble/setup.bash
source "${PIPER_REAL_WS:-../real_piper_yolo_graspnet}/install/setup.bash"
.venv/bin/python agent.py --mode real --profile grasp
```

| 对 ROSA 说 | 结果 |
| --- | --- |
| 启动积木感知和 GraspNet，查看当前识别到的物体 | 使用 `block` 类别，并检查当前检测和候选 |
| 为积木预演抓取、保持和原位放回 | 从真机零位规划接近、下降、抬升、返回、退让和回零。返回任务编号 |
| 查询任务结果 | 查看 `state=prepared`、候选名、TCP 抓取坐标及抬升高度。预演结果有效期为 90 秒 |
| 抓取积木并保持 | 操作者在终端确认，夹爪通过开闭反馈检查后执行抓取和抬升。通过开度复核后进入 `held` |
| 查询持物状态 | 查看最近一次持物开度和任务状态 |
| 放回物体 | 操作者再次确认。沿预演轨迹下降至原抓取位，松爪、退让、回零 |
| 取消任务 job_编号 | 请求停止当前轨迹并保留夹爪状态。动作中断时按 `needs_recovery` 现场处置 |

## 从仅规划切换到真机动作

[模块配置](../config/modules.yaml)默认 `real_hold_place_motion: false`。在当前工位检查真机反馈、夹爪全开和全闭参考、桌面与碰撞场景、手眼标定和 TCP 抓取高度后，才将该值设为 `true`，重启 ROSA 和真机执行器，重新预演。首次动作按测试手册分段、低速、有人值守地进行。真实夹爪反馈为 0 或不稳定时，抓取流程会在臂移动前停止。

`held` 表示最近一次反馈通过了持物开度判定。`placed` 表示夹爪张开反馈与机械臂回零反馈通过。现场仍需观察物体抬离桌面、保持和落稳。MoveIt 使用张开夹爪模型检查轨迹，规划场景需要覆盖实际桌面和障碍。执行器重启会清空持物状态，现场确认夹爪已空且机械臂处于零位后再启动下一轮。
